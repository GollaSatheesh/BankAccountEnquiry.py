# ATM Banking System 🏧

A console-based ATM simulation built with Python using Object-Oriented Programming concepts.

## Features
- Account validation with account number and PIN
- Deposit (multiples of ₹100 only)
- Withdrawal with balance check
- PIN change with old PIN verification
- Mini statement with transaction history
- Simulated processing delay using `time.sleep()`

## Concepts Used
- Classes and Objects
- Class variables vs Instance variables
- Methods and Encapsulation
- Loops and Conditionals

## How to Run
```bash
BankAccountEnquiry.py
```

## Default Credentials (for testing)
- Account Number: `6304`
- ATM PIN: `1234`

## Tech Stack
- Python 3.x
